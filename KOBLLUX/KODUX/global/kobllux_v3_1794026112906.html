📐 Unidades fluidas --u-base

1. O que é --u-base

É uma unidade-base fluida declarada em :root. Todas as medidas do layout são múltiplos dela via calc().

:root {
  --u-base: clamp(3px, calc(100vw / 44), 20px);
  /*         ▲piso     ▲fator          ▲teto */
}

No caso base (--u-base ≈ 10px, i.e., 100vw = 440px): 1u = 10px.

2. Regra prática

N = px / 10

calc(var(--u-base) * N)

// Exemplos
gap: 12px        → gap: calc(var(--u-base) * 1.2)
padding: 24px    → padding: calc(var(--u-base) * 2.4)
border-radius:32px → calc(var(--u-base) * 3.2)

4. NÃO converter

  • border: 1px solid — hairline proposital
  • z-index — número abstrato, sem relação com tamanho
  • %, vh, vw, dvh, rem, em — já relativos
  • transform: scale(...), opacity — adimensionais
  • transition: .28s — tempo, não tamanho

Exceção útil: box-shadow, backdrop-filter: blur(Npx), filter: blur(Npx) são px e devem ser convertidos.

5. Ajustar o clamp

/* Telas grandes: baixar teto (topbar deixa de inflar) */
--u-base: clamp(3px, calc(100vw / 44), 14px);

/* Telas pequenas: subir piso (evita UI minúscula) */
--u-base: clamp(6px, calc(100vw / 44), 20px);

/* Velocidade: divisor maior = escala mais lenta */
--u-base: clamp(3px, calc(100vw / 56), 20px);

6. Slider manual

O slider flutuante seta --u-base inline no <html> (sobrescreve o clamp).

  • Arrastar: valores 3–18
  • Duplo clique: reseta para o clamp()
  • 10 = tamanho original mobile · 18 = 1.8×

7. API window.UBase

UBase.get()              // → 10 (px atual)
UBase.set(14)            // trava em 14px
UBase.reset()            // volta ao clamp()
UBase.config({ ceil: 14, floor: 5, div: 40 })
UBase.moveSlider('header-center')
UBase.readme()           // abre este modal
UBase.autoConvert()      // px→calc em
