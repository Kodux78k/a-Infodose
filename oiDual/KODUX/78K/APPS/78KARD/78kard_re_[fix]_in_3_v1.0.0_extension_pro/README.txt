COMO INSTALAR NO CHROME / EDGE / OPERA:
--------------------------------------------------------
1. Extraia o conteúdo deste ficheiro ZIP para uma pasta local.
2. Abra o browser e navegue até: chrome://extensions (ou edge://extensions).
3. Ative a opção "Modo do programador" (Developer Mode) no canto superior direito.
4. Clique em "Carregar sem compactação" (Load unpacked).
5. Selecione a pasta onde extraiu o conteúdo do ZIP (aquela que contém o "manifest.json").
6. Pronto! O ícone da sua aplicação aparecerá no menu de extensões.

COMO CONFIGURAR O SAFARI WEB EXTENSION (MACOS/XCODE):
--------------------------------------------------------
O pacote inclui a pasta "SafariPackage" com as definições Swift e Plist para compilar no Xcode.
Para converter diretamente o diretório gerado:
1. Abra o Terminal no macOS.
2. Execute o comando de conversão oficial da Apple:
   xcrun safari-web-extension-converter /caminho/para/pasta_extraida
